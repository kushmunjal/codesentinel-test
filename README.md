# CodeSentinel Test Repository

A sandbox repository for automated CI/CD code reviews, AST-based security checks, and AI issue triage verification.

## Features
- **Addition & Subtraction**: Standard arithmetic methods with type flexibility.
- **Multiplication**: Strict scalar multiplication with type validation.
- **Defensive Division**: Division operations featuring explicit zero-division guards and informative error feedback.
- **Power Calculation**: Exponentiation supporting positive and negative powers.
- **Automated Verification**: Integrated pytest test suite in `tests/test_calculator.py`.
